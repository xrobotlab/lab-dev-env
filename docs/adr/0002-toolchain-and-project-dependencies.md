# ADR 0002: 共通ツールと研究固有依存関係を分離する

- 状態: 採用
- 日付: 2026-10-07

## 背景

研究室全員が使用するCLIと、個別研究のPythonライブラリを同じグローバル環境へ入れると、研究ごとのバージョン差を再現できません。

一方、B3ゼミではDYNAMIXEL SDKなど全員が利用できる共通環境も必要です。

## 決定

- Python、Node.js、uv、just、PlatformIO、ghなどの共通ツールはmiseで管理する
- B3ゼミ共通Python依存関係は `b3/` のuv環境で管理する
- 研究コードが利用するPython依存関係は、各研究リポジトリ自身の `pyproject.toml` と `uv.lock` で宣言する
- B3共通環境を研究コードから直接使い回さない

## 結果

- PCの標準工具と研究固有依存関係の責務が分離される
- 同じDYNAMIXEL SDKを使う場合でも、研究リポジトリ側に依存関係が明示される
- 研究ごとに異なるバージョンを再現できる
