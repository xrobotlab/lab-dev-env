# ADR 0006: B3教材向けにKiCad 9.0系を固定する

- 状態: 採用
- 日付: 2026-10-07

## 背景

研究室のB3電子工作教材はKiCad 9.0系を前提として作成されています。調査時点の現行安定版は10系ですが、教材と操作画面・挙動が変わる可能性があります。

## 決定

教材側を更新するまでは、Windows標準環境のKiCadを9.0系最終版の9.0.9へ固定します。

## 結果

- B3ゼミで教材と実際の画面を揃えやすい
- KiCadの最新メジャーバージョンを自動追従しない
- 教材を10系へ更新する際は、このADRを置き換える判断が必要
