# ADR 0004: DYNAMIXEL Wizard 2を手動導入とする

- 状態: 採用
- 日付: 2026-10-07

## 背景

DYNAMIXEL Wizard 2はB3ゼミで使用しますが、調査時点でWindows配布物の版付きURL、SHA-256、インストーラー形式、無人導入用CLI引数を十分に検証できませんでした。

未確認の `/S`、`/silent`、`/VERYSILENT` などを推測で使用すると、将来の配布形式変更や意図しない権限昇格につながる可能性があります。

## 決定

DYNAMIXEL Wizard 2はROBOTIS公式配布から手動導入します。

`lab-dev-env` は公式導入先を案内し、`just doctor-full` で実行ファイルを検出します。

版付き配布URL、SHA-256、導入方式を検証できるまでは自動ダウンロード・自動実行を追加しません。

## 結果

- 未検証のインストーラー引数を使用しない
- B3利用者には一部手動操作が残る
- 導入自動化を追加する場合は配布物の再調査が必要

調査内容は [インストーラー・配布物の確認根拠](../reference/installer-evidence.md) に記録します。
