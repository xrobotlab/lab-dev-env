# ADR 0003: 通常セットアップをユーザー権限に限定する

- 状態: 採用
- 日付: 2026-10-07

## 背景

研究室の貸与PCでは、利用者が常に管理者権限を持つとは限りません。初期構築全体を管理者権限に依存させると、再現性と安全性が低下します。

## 決定

標準CLIと可能なGUIアプリはユーザー領域へ導入します。

bootstrap自体を管理者として実行することは認めません。

ドライバ、WSL 2の初回有効化、Linuxのグループ設定、NVIDIA関連などOS側の変更は通常bootstrapから分離します。

GUIアプリの前提コンポーネントが管理者権限を要求した場合は、自動昇格せず中止して管理者へ相談します。

2026-10-08の [ADR 0009](0009-standard-gui-package-management.md) によりGUIのOS別パッケージ管理を導入します。Homebrew自体の初期導入や共有領域を使うcaskは通常bootstrapから分離し、制御機能が利用できない場合は公式手動手順へ誘導します。

## 結果

- 多くの貸与PCで利用者自身が標準環境を構築できる
- OS全体を変更する処理がbootstrapに混入しにくい
- 一部のハードウェア・OS設定は別途管理者作業が必要になる
