# ADR 0008: 3Dプリンタ用スライサーの標準案内をBambu Studioとする

- 状態: 採用
- 日付: 2026-10-07

## 背景

スライサーには複数の選択肢がありますが、研究室の3DプリンタはBambu Lab製で統一されています。

プリンタとスライサーの組み合わせを揃えることで、設定・トラブル対応・操作方法を研究室内で共有しやすくなります。

## 決定

研究室の3Dプリンタを利用する場合はBambu Studioを標準スライサーとして案内します。

Bambu Studioはbootstrapで自動導入せず、各OS向けの公式Public Releaseを手動導入します。

## 結果

- 利用者がスライサー選定で迷いにくくなる
- Bambu Labプリンタの設定・操作ノウハウを共有しやすくなる
- 3Dプリンタを使用しない利用者には不要なソフトを導入しない
