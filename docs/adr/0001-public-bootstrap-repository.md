# ADR 0001: 初期構築リポジトリをPublicにする

- 状態: 採用
- 日付: 2026-10-07

## 背景

貸与PCの初期状態では、GitHubアカウント作成、研究室GitHub組織への招待、参加が完了していない場合があります。

初期構築そのものを組織参加に依存させると、環境構築の開始前に別の手続きが必要になります。

## 決定

`xrobotlab/lab-dev-env` はPublicリポジトリとして運用します。

WindowsではGitがなくてもGitHub UIのDownload ZIPから取得し、`bootstrap.cmd` を開始できる経路を維持します。

## 結果

- GitHub組織への参加前でも初期構築を開始できる
- リポジトリ内に秘密情報、内部URL、個人情報、秘密鍵を置けない
- 公開して問題のない設定・スクリプトだけを管理対象とする
