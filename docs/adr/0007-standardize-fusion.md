# ADR 0007: 3D CADの標準案内をAutodesk Fusionとする

- 状態: 採用
- 日付: 2026-10-07

## 背景

3D CADには複数の選択肢がありますが、学科の授業でAutodesk Fusionを使用しています。

授業ですでに学んだ操作体系を研究でも利用できれば、新しく別のCADを選定・習得するコストを減らせます。

## 決定

3D CADを必要とする利用者にはAutodesk Fusionを研究室の標準案内とします。

Fusionはbootstrapで自動導入せず、各利用者がAutodesk Accountと利用資格を確認して公式手順から導入します。

Linuxへのネイティブ導入は標準経路に含めません。

## 結果

- 授業と研究で3D CADの操作経験を共用できる
- CAD選定で迷いにくくなる
- Autodeskアカウントや教育利用資格を研究室共通スクリプトから分離できる
