# ADR 0006: PCB設計ツールとしてKiCadを研究室標準にする

- 状態: 採用
- 日付: 2026-10-07

## 背景

回路・PCB設計にはKiCadのほか、Fritzingなど複数の選択肢があります。利用者ごとに異なるツールを選ぶと、初めて基板を設計する際に選定から始める必要があり、研究室内で操作方法や設計上の助言を共有しにくくなります。

研究室ではKiCadの利用者が多く、既存利用者から操作や設計について助言を受けやすい状況があります。

またKiCadは回路図からPCBレイアウトまで扱え、JLCPCBなどの基板製造サービスへ渡せるGerber・ドリル等の製造データを出力できます。

## 決定

研究室で回路・PCBを設計する際の標準ツールとしてKiCadを採用し、`lab-dev-env` の標準環境に含めます。

新しくPCB設計を始める利用者が特別な理由なく別ツールを選ぶ必要がない状態を作り、研究室内で知識・操作方法を共有しやすくします。

KiCadの具体的なバージョンはこのADRでは固定せず、`docs/reference/tool-versions.md` と各OSの導入手順で管理します。現在の固定版は9.0系です。

## 結果

- 新規利用者がPCB設計ツールの選定で迷いにくくなる
- 研究室内でKiCadの操作・設計ノウハウを共有しやすくなる
- JLCPCBなどへ発注するための製造データを共通の手順で作成しやすくなる
- 将来KiCadのメジャーバージョンを更新しても、ツール選定のADRは維持できる
