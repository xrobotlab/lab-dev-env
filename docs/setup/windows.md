# Windows 11セットアップ

初期導入は [READMEのWindows 11手順](../../README.md#windows-11) を参照してください。標準GUI6本と通常権限での導入経路は [GUIアプリ](gui-apps.md) にまとめています。未検出の標準GUIは公式手動手順で準備し、リポジトリのルートで `just doctor-full` と `just b3-check` を実行します。

GUIの版は固定しません。既存版を保持し、bootstrapは不足分だけを導入します。DockerとAutodesk Fusionは必要な場合だけ導入します。管理者権限が必要なOS設定・ドライバは研究室の管理者へ相談してください。
