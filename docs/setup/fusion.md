# Autodesk Fusion

3D CADを行う場合の研究室標準ソフトとしてAutodesk Fusionを案内します。

学科の授業でもFusionを使用するため、授業で得た操作経験をそのまま研究へ持ち込めます。

## 導入対象

- Windows 11
- macOS

AutodeskはLinuxへのFusionの直接インストールをサポートしていません。Linux PCでFusionが必要な場合は、Windows / macOSの端末または利用資格に応じたWeb版を使用してください。

## 導入

Autodesk Accountへサインインし、利用可能なFusionライセンスまたはEducation entitlementからインストーラーを取得します。

- [Autodesk Fusionのダウンロード・インストール手順](https://www.autodesk.com/jp/support/technical/article/caas/sfdcarticles/sfdcarticles/JPN/How-to-download-Fusion-360.html)
- [Autodesk Fusion Education](https://www.autodesk.com/education/edu-software/fusion)

教育機関向け利用では、各学生・教員が固有のAutodesk IDでFusionへサインインします。

## lab-dev-envで自動導入しない理由

Fusionの導入にはAutodesk Accountと利用資格の確認が必要です。研究室共通の認証情報をbootstrapへ持たせず、各利用者が公式手順で導入します。
